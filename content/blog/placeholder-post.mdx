## What a post looks like

A post is one MDX file in `content/blog`. The filename is the slug and does not change once published. The frontmatter carries `title`, `description`, `date`, and optionally `updated` and `draft`; anything else fails the build.

- Headings inside a post start at the second level. The title is the page heading.
- Links to other pages on this site use site-relative paths.
- Code blocks render in the payload style used on automation pages.

> Quotes render as a dimension line off the left margin.
